反魂 · shin · renacer

No es un «delay aleatorio». Es infraestructura.

Lo que marca la diferencia frente a un bot de un solo archivo: decisiones tomadas pensando en que el bot lleve meses encendido sin que nadie lo mire.

Anti-ban de verdad

Jitter gaussiano (no un random de juguete), calentamiento diario por número y un monitor de riesgo de 0 a 100 que pausa los envíos solo, sin apagar el bot.

σ 0.25 · 1200 ms base · warm-up 20→500/día

Tu sesión no se borra sola

Un micro-corte de red (408, 428, 503) no es una sesión muerta: el bot reintenta en modo paciente. Solo se limpia cuando WhatsApp dice que la sesión ya no existe.

SQLite con WAL · chmod 600 · checkpoint al arrancar

Cola de envío con prioridad

Nada sale «a lo loco»: los mensajes van en fila, con reintento. Los comandos críticos (menú, ping, dueño) se cuelan al frente y responden al instante.

serial + reintento + ventana de prioridad

Menú nativo, no texto plano

Tarjeta con botones y lista desplegable por categorías, y si el WhatsApp del usuario no sabe mostrarla, el bot cae solo a un menú clásico legible.

MENU_STYLE=auto · text

Estado, riesgo, cola, grupos y memoria en tu propio navegador. Solo escucha en tu máquina salvo que lo abras a la red, y entonces exige contraseña y bloquea la fuerza bruta.

Instalarlo es copiar, pegar y escanear un código.

Funciona en un teléfono con Termux y en cualquier servidor con Node 22.5 o superior. No hace falta saber programar.

Usa un número secundario

WhatsApp puede sancionar cuentas que automatizan mensajes. Shin-MD trae el anti-ban más cuidado que existe en su categoría, pero ningún bot es inmune: no arriesgues tu número personal.

1

Prepara Termux

# instala lo necesario
pkg update && pkg upgrade -y
pkg install -y git nodejs python ffmpeg
2

Descarga el bot e instala sus dependencias

git clone https://github.com/riokuroxi-svg/Shin-MD
cd Shin-MD
npm install
3

Configura tu número

cp .env.example .env
nano .env

Rellena PAIRING_NUMBER con tu número (solo dígitos, con lada: 521...) y deja PAIRING_METHOD=code.

4

Enciende el bot y vincula

npm start -- --code

Te mostrará un código de 8 caracteres (por ejemplo 7QK4-2ZP9). En WhatsApp: Dispositivos vinculados → Vincular con número de teléfono y lo escribes. ¿Prefieres QR? Usa npm start -- --qr.

1

Instala Node 22 en el servidor

# Debian / Ubuntu
curl -fsSL https://deb.nodesource.com/setup_22.x | sudo -E bash -
sudo apt-get install -y nodejs ffmpeg git

Descarga, configura y arranca

git clone https://github.com/riokuroxi-svg/Shin-MD

3

Que siga vivo al cerrar la terminal

# con pm2
npm install -g pm2
pm2 start index.js --name shin-md -- --code
pm2 save && pm2 startup

Sin terminal interactiva el bot toma el número del .env solo: nunca se queda esperando el teclado.

Seguridad del panel

Por defecto solo escucha en 127.0.0.1: nadie de tu red lo ve. Si lo expones (LOOPBACK=0) exige contraseña, valida el usuario admin y bloquea a quien insista: 10 intentos fallidos y esa IP espera 5 minutos.

  • Contraseña obligatoria para salir de tu máquina; sin ella, vuelve solo a localhost.
  • Nada de ficheros sensibles: rutas tipo ../.env o logs responden 404 sin filtrar información.
  • Sin secretos en el código: tokens y claves viven en tu .env, fuera del repositorio.
